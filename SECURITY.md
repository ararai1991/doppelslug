# Security policy

## Supported versions

Security fixes are released for the latest version of Doppelslug.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub: [Report a vulnerability](https://github.com/ararai1991/doppelslug/security/advisories/new). Include the affected version, the steps to reproduce, and what an attacker could do (for example, which user role is needed).

You can expect an acknowledgement within a few days. Confirmed issues are fixed in a new release, credited to the reporter if they wish, and disclosed after users have had time to update. You may also report through the [Wordfence](https://www.wordfence.com/threat-intel/) or [Patchstack](https://patchstack.com/database/report) vulnerability programs.
